# GOELTA ERP System

The new Odoo-style React sales workspace is in [`sales-app/`](sales-app/README.md).

```sh
cd sales-app
npm ci
npm run dev
```

Includes quotations, sales orders, customer invoices/payments, vendor RFQs/purchase orders, customers, products, Excel imports and PDF exports. Records are saved in browser local storage.

The earlier prototype remains in `Sample UI sales/`.
